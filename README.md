# Вовремя — сайт-визитка для GitHub Pages

Готовый набор файлов для репозитория `<ваш-логин>.github.io`.
Всё уже подготовлено — осталось загрузить на GitHub (аккаунт нужен ваш).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Визитка приложения → `https://<логин>.github.io/` |
| `app-ads.txt` | Файл для Яндекс РСЯ → `https://<логин>.github.io/app-ads.txt` |
| `icon.png` | Иконка приложения (фавикон + превью в соцсетях), 512×512 |
| `robots.txt` | Разрешает индексацию сайта поисковиками |
| `.nojekyll` | Отключает обработку Jekyll (файлы отдаются как есть) |

Ссылки на визитке уже расставлены: «Скачать в RuStore» → карточка приложения,
«Поддержка» → ВК (@runhelp).

## Заливка на GitHub Pages

1. На github.com создайте **New repository** с именем `<ваш-логин>.github.io`
   (Public, галочка «Add a README file» не обязательна).
2. В репозитории: **Add file → Upload files** → перетащите **все файлы из этой папки**
   (`index.html`, `app-ads.txt`, `icon.png`, `robots.txt`, `.nojekyll`) → **Commit changes**.
   ⚠️ Файлы должны лежать в КОРНЕ репозитория, не в подпапке.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**,
   папка **/ (root)** → **Save**.
4. Подождите 1–2 минуты и проверьте:
   - `https://<логин>.github.io/` — визитка;
   - `https://<логин>.github.io/icon.png` — иконка;
   - `https://<логин>.github.io/app-ads.txt` — текст файла (не 404).

## Важно про app-ads.txt

Сейчас в папке лежит **заглушка**. Перед заливкой замените её на настоящий файл:
partner.yandex.ru → **Настройки → Общие** → кнопка **app-ads.txt** → скачать.
Содержимое скачанного файла вставьте в `app-ads.txt` (имя файла менять нельзя).

## После заливки

1. В RuStore Консоли в карточке приложения в поле **«Веб-сайт»** укажите
   `https://<логин>.github.io`.
2. Яндекс РСЯ раз в сутки проверит файл по этому домену; статус появится в интерфейсе
   (Настройки → Общие). Если нужно — нажмите **«Отправить на проверку»**.

## Проверка, что всё ок

- Открывается визитка, кнопки ведут на RuStore и ВК.
- `app-ads.txt` отдаётся браузером (виден текст, а не 404).
- В карточке RuStore указан тот же домен, что и в браузере.
